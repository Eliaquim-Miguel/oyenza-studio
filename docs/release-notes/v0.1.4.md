**New: the Oyen theme.** Right-click the island, then **Theme › Oyen**. Oyen, the Oyenza cat, moves into the island: he peeks over its edge while it rests, watches your pointer when it comes near, sits beside the clock and bobs along while music plays. He sleeps from midnight to five, and his orange becomes the accent colour. The black island stays the default (**Theme › Classic**), and nothing else changes in it.

**Also:** a sharper tray icon: Windows now uses the icon's own small sizes instead of shrinking the big one.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
