**Romaji under Japanese lyrics on every PC.** Oyen Poni reads Japanese lyrics with Windows' own reading analyzer, but most Windows 11 PCs outside Japan don't have its data (it comes with Japanese typing), so lines with kanji had no romaji under them. Now Oyen Poni reads those songs with its own Japanese dictionary, built in: every line gets its romaji, with nothing to install and nothing leaving your PC. Where Windows has its Japanese data, Windows still does the reading.

**The dots after an intro or a break fold away.** The • • • that mark an intro or an instrumental break now fold away once the next line starts, as in Apple Music, instead of staying above the lyrics for the rest of the song.

The dictionary makes the download about 4 MB bigger. The download now also includes `THIRD-PARTY-NOTICES.txt`, with the licenses of the dictionary and the code Oyen Poni is built from.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
