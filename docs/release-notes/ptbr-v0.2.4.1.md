# Oyenza Studio — edição comunitária PT-BR 0.2.4.1

Primeira versão para download do fork comunitário em Português do Brasil.

## Principais mudanças

- Português do Brasil como idioma padrão, com opção para voltar ao inglês.
- Calendário, datas, menu da bandeja e principais páginas traduzidos.
- Relógio, Oyen, Minimal e Status permanecem visíveis como uma pequena barra sobre janelas maximizadas.
- A ilha compacta abre ao passar o mouse e volta ao visual original quando a janela deixa de estar maximizada.
- O tamanho original do Minimal foi preservado para evitar que o conteúdo fique espremido.

## Downloads

- `Oyenza-Studio-PTBR.exe`: executável portátil para Windows 10 e 11.
- `Oyenza-Studio-PTBR-portable.zip`: o mesmo executável, acompanhado da licença e dos avisos de terceiros.

Esta edição não possui assinatura digital. Por isso, o Windows SmartScreen pode pedir confirmação na primeira abertura. Confira os hashes SHA-256 publicados abaixo antes de executar o arquivo.

## Integridade dos arquivos

Os hashes SHA-256 estão incluídos na descrição da release e podem ser conferidos no Windows com:

- `Oyenza-Studio-PTBR.exe`: `E706ACD18F3B68FA2FBA0A14A08E663BA8543E4D9344C77D8193D67E2C44CF95`
- `Oyenza-Studio-PTBR-portable.zip`: `67ED1F98D5B4FE7FE84132C8C1F2BC9D5145A008133860797B286F75343DE7B7`

```powershell
Get-FileHash .\Oyenza-Studio-PTBR.exe -Algorithm SHA256
```
