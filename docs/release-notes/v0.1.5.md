**Smoother motion.** The island now draws on the GPU and times every frame to your screen's refresh, so it no longer jumps at the start of a morph or jitters at its edges while it changes size. The equalizer moves at about 60 fps.

This is checked on Windows in our automated tests, but not yet on every graphics card or high-refresh screen. If the island looks wrong on your PC, set the environment variable `PONI_RENDERER=software` to go back to the previous drawing, and tell us in an issue.

**Also:** groundwork for a Microsoft Store version, which will install without the SmartScreen warning. Nothing changes for copies installed from GitHub.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
