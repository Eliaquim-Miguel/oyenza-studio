**Phone drop: files between your phone and the Shelf.** Open the Shelf and click **Phone** (on an empty shelf, the **Phone drop** tile). Scan the QR code with your phone's camera, pick photos or files on the page that opens, and tap **Send**. The island asks first: **Accept** or **Decline**. Accepted files go to `Downloads\Oyen Poni` and onto the Shelf. The page also lists the files on your Shelf, so you can save them on the phone. It works with iPhone and Android, and there's nothing to install on the phone.

- **Same Wi-Fi:** your phone and your PC need to be on the same network. The first time, Windows asks whether Oyen Poni may use the network: allow it on private networks. If Windows treats your Wi-Fi as a public network, set it to private (Settings > Network & internet > Wi-Fi), or the phone can't reach the PC.
- **Private:** each session gets its own secret link, which only the QR code carries. It stops working when you click **Done**, and after 10 minutes without a phone. Nothing goes through the internet, and nothing is saved until you accept.
- **Not AirDrop:** an iPhone only AirDrops over Apple's own Wi-Fi link, which Windows Wi-Fi drivers can't run, so Phone drop uses the phone's browser instead. It works in both themes.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
