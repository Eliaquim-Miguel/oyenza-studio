**Show over games: FPS, GPU and CPU on the island.** Switch on Show over games (System › **Games**, or right-click the island › **In full-screen apps** › **Show FPS, GPU and CPU over games**). While a game fills the screen in borderless full-screen, the island becomes a small readout: frames per second, the graphics card's load and temperature, and the CPU's load, once a second. Hover it to open the island as usual. Turning it on keeps the island on top of full-screen apps, and picking Hide there turns it off.

**Counted from Windows, not from inside the game.** Frames come from Windows' own log of each frame a game hands to the screen, the way Intel's PresentMon and Xbox Game Bar count them. Nothing is loaded into the game, so anti-cheat has nothing to see. DirectX 9 to 12 games count from their own Present calls, Vulkan and OpenGL games from the graphics kernel's log. Only the game in front is counted, and nothing runs while no game is in front or while the readout is off.

**A one-time OK for FPS.** Windows lets only admins and its Performance Log Users group read that log. The first time, System › Games shows **Allow FPS**. Windows then asks once for an admin OK, which adds your account to that group (Xbox Game Bar's FPS counter asks the same), and FPS shows from your next sign-in. Until then the readout shows GPU and CPU and a dash for FPS. To undo it, remove your account from Performance Log Users; the README says how.

**System › Games.** A new Games tile on the System page holds the switch, the one-time OK, the frame rate's last minute, frame times (the average and the slowest in the last second) and the game in front.

A game in exclusive full-screen mode still covers the island, as it covers every window. Show over games is on Windows only.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**On a Mac:** open `Oyen-Poni-Mac.dmg` and drag Oyen Poni into Applications. It isn't signed with an Apple Developer ID yet, so the first time macOS warns you, click **Done**, then open **System Settings → Privacy & Security** and click **Open Anyway**.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
