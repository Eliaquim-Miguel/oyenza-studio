**Settings in the island.** A gear in the island's header, right of the pin, opens Settings. Sign in to Oyenza there (signed in, it shows who, a **Show amounts** switch and **Disconnect**), pick the theme and the idle look, and turn synced lyrics, lyrics pronunciation, sounds, clipboard history, hiding in full-screen apps and starting with Windows on or off. Changes save at once. Signed out, the Health page's "Sign in with Oyenza" is now a button. The tray and right-click menus still have everything too.

**Romaji under kanji lines.** Japanese lyrics now get their reading in Latin letters under every line, kanji included, like Apple Music's Show Pronunciation. Before, only lines written all in kana got one: Oyen Poni asked Windows' Japanese reader from the wrong kind of thread, and Windows turned every request down.

The kanji readings come from Windows' own Japanese reader, which needs Windows' Japanese typing. Windows 11 doesn't include it unless you've added Japanese. If kanji lines still have no romaji, add it in **Windows Settings › Time & language › Language & region › Add a language › Japanese** (this also adds a Japanese keyboard). Or run this in PowerShell as administrator, which adds only the reading data:

```
Add-WindowsCapability -Online -Name Language.Basic~~~ja-JP~0.0.1.0
```

**The island closes as soon as you leave it.** It used to wait about 0.4 s before it started to shrink. Now it starts closing on the next frame. Point back at it while it's closing and it opens again from where it is.

**Install:** download `Oyen-Poni-Setup.exe` and run it. It installs just for you (no admin rights) and can start with Windows. Or unzip the portable zip and run `Poni\poni.exe`.

**Upgrading from 0.1.x:** run the new installer. It upgrades in place and keeps your settings and data (`%APPDATA%\Poni`).

The build isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
